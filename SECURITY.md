# Security policy

- ⚠️ **Do not open a public issue to report a security vulnerability.**
- Report it privately instead:
  [open a security advisory](https://github.com/evilnet/seance/security/advisories/new).
- Seance is a fork of [The Lounge](https://github.com/thelounge/thelounge) but
  is not maintained by them. Do not send reports about Seance to
  `security@thelounge.chat` or to `#thelounge` on Libera.Chat.
